# 需求分析说明书 — Rust 股票交易终端 `tdesk`

| 项目 | 内容 |
| --- | --- |
| 版本 | v0.1.0（首版可运行原型） |
| 日期 | 2026-11-12 |
| 定位 | **本地纸面交易 / 教学与策略验证终端**，非实盘下单系统 |
| 技术栈 | Rust 2021 / egui 0.31 + eframe 0.31（纯 Rust 原生 GUI，单二进制） |
| 关键约束 | 完全离线可运行、行情可复现、金额用整数、无真实资金与券商连接 |

---

## 1. 目标与边界

### 1.1 目标

1. 交付一个可在 macOS 上 `cargo run` 直接打开的桌面交易终端，具备行情、下单、持仓、盈亏、回测的完整闭环。
2. 交易核心（撮合 / 结算 / 风控 / 回测）与 UI 完全解耦，可独立在无 GUI 环境下被 CLI 与自动化测试驱动。
3. 多市场规则可配置：A 股、美股、港股在涨跌颜色、T+N、涨跌停、最小交易单位、费率上差异明显，必须抽象成 `MarketRules` 而不是散落的 `if`。

### 1.2 不在范围内（明确排除）

- 真实券商/交易所连接、真实资金、真实账户与凭据管理。
- 实盘合规要求（投资者适当性、留痕审计、行情许可、熔断与灾备）。
- 多用户、服务端、数据库、网络加密、分布式撮合。
- 高频/低延迟优化（本系统为单线程、毫秒级无关）。

> ⚠️ 本项目生成的行情是**确定性合成的随机数据**，任何回测收益均不构成投资建议。

## 2. 角色与用例

| 角色 | 用例 | 验收点 |
| --- | --- | --- |
| 交易员 | 切换市场 / 标的，查看 K 线、成交量、MA5/MA20 | 切换后行情、涨跌幅、颜色按市场规则刷新 |
| 交易员 | 下限价单 / 市价单、撤单 | 委托状态在 挂起→部分成交→成交/已撤/拒绝 间正确流转，生成成交回报 |
| 交易员 | 查看资金、持仓、浮盈浮亏、T+1 可卖数量 | 买入当日 A 股 `可卖=0`，换日后释放；美股/港股即时可卖 |
| 风控 | 校验资金、持仓、手数、涨跌停、单笔集中度 | 违规下单被拒绝并给出**可读中文原因**，账户零变更 |
| 量化研究员 | 运行 SMA 金叉/死叉策略回测 | 输出权益曲线、总收益、最大回撤、胜率、夏普，且无未来函数 |
| 开发者 | `cargo test` / CLI 无头演示 | 不启动窗口即可验证撮合、结算、风控、回测、UI 渲染 |

## 3. 功能需求

### FR-1 多市场规则（配置化）

| 规则 | A 股（沪深） | 美股 | 港股 |
| --- | --- | --- | --- |
| 计价 | ¥ CNY | $ USD | HK$ HKD |
| 涨跌颜色 | **红涨绿跌** | 绿涨红跌 | 红涨绿跌 |
| 结算 | **T+1**（当日买入不可卖） | T+0 | T+0 |
| 涨跌停 | 前收盘 ±10%（按最小价位取整） | 无 | 无 |
| 最小交易单位 | 100 股 / 手 | 1 股 | 100 股（首版按标的表配置） |
| 最小价位 | 0.01 | 0.01 | 0.01（首版简化，见 8.2） |
| 佣金 | 万 3，最低 ¥5 | 0（首版简化） | 万 3 |
| 印花税 | 卖出 万 5 | 0 | 卖出 千 1 |
| 过户费 | 万 0.1 | 0 | 0 |

> 中国区约定：A 股与港股按国内习惯**红涨绿跌**；美股按欧美习惯**绿涨红跌**。UI 必须随所选市场动态切换，不可写死。

### FR-2 行情

- 内置 3 组共 14 只标的（A 股 5 / 美股 5 / 港股 4），含代码、名称、基准价、波动率。
- 确定性合成日 K 线（OHLCV），同一 `(市场, 标的, 种子)` 重复调用结果完全一致。
- 逐 tick 推进价格，形成当前未完成 K 线；支持 播放/暂停、速度调节、推进一日（触发 T+1 结算）。
- 支持 `MarketDataSource` trait 扩展：内置 `SyntheticSource`，另提供 `CsvSource` 导入 `ts,open,high,low,close,volume`。

### FR-3 下单与撮合

- 订单类型：限价单、市价单（首版市价单剩余量自动撤单，等价 IOC）。
- 订单状态：`Pending / PartiallyFilled / Filled / Cancelled / Rejected`。
- 撮合原则：**价格优先、时间优先**；撮合价取**先在簿上的挂单价**（maker price）。
- 支持部分成交、撤单、成交明细（时间、价格、数量、手续费、对手单号）。
- 自成交防范：同一账户的买卖挂单相遇时撤销旧挂单，不产生成交。
- 撮合簿由做市商（Maker）挂单提供流动性，每 tick 在最新价上下若干档刷新。

### FR-4 账户与结算

- 初始资金 ¥1,000,000.00（美股/港股同数值但按各自币种显示）。
- 现金、持仓成本、已实现盈亏、浮盈浮亏、总权益、累计手续费。
- T+1：`locked_today` 记录当日买入，`roll_day()` 时转入 `available`。
- 卖出按移动加权平均成本结转已实现盈亏；费用计入成本/收益。

### FR-5 风控

下单前同步校验，任一失败即拒绝且**账户零副作用**：

1. 数量 > 0 且为最小交易单位整数倍；
2. 限价 > 0，且落在涨跌停区间内（有涨跌停的市场）；
3. 买入：`数量 × 委托价 + 预估费用 ≤ 可用现金`；市价单按上界价/最优卖价估算；
4. 卖出：`数量 ≤ 可卖数量`；
5. 单笔名义金额 ≤ 总权益的 50%（集中度上限，可配置）。

### FR-6 回测

- `Strategy` trait + 内置 `SmaCrossStrategy(fast=5, slow=20)`。
- **无未来函数**：第 i 根 K 线收盘产生信号，第 i+1 根 K 线开盘成交。
- 复用与实盘一致的 `Account` / `FeeSchedule` / `MarketRules` 结算逻辑。
- 指标：总收益率、最大回撤、胜率、交易次数、年化夏普（√252）。

### FR-7 UI

- 顶栏：市场切换、行情播放/暂停、速度、推进一日、明暗主题、重置账户。
- 左侧：自选列表（最新价、涨跌额、涨跌幅，按市场配色）。
- 中央：K 线 + 成交量 + MA5/MA20 + 最新价虚线 + 十字光标与数值提示。
- 右侧：下单面板（买/卖、限价/市价、价格、数量、25%/50%/全额快捷键、风控提示、提交）。
- 底部标签页：委托、成交、持仓、资金、回测。
- 状态可视化：可撤单按钮、拒绝原因、订单状态色标。

### FR-8 工程化

- Cargo workspace 四个 crate，分层依赖单向：`app/cli → data → core`，`core` 零 UI 依赖。
- `tdesk-cli` 无 GUI 端到端演示；`tdesk-app` 的 UI 渲染与 `eframe::App` 解耦，支持 `egui::Context::run` 无头冒烟测试。
- 整数运算：`Price`（最小价位整数倍）、`Money`（货币最小单位 / 分），全流程无浮点金额误差。

## 4. 非功能需求

| 类别 | 要求 | 验证方式 |
| --- | --- | --- |
| 正确性 | 金额/数量恒等式：`现金 + 持仓市值 = 总权益`；成交前后账户守恒 | 单元测试 + CLI 断言 |
| 确定性 | 同种子行情与回测结果可复现 | 两次生成逐字段比对 |
| 可测试性 | 核心逻辑不依赖系统时间 / 网络 / 窗口 | `cargo test -p tdesk-core` 在纯命令行通过 |
| 性能 | 单次 tick（含刷新 10 档流动性 + 渲染一帧）< 16 ms | CLI 基准计时打印 |
| 可维护性 | `cargo clippy -- -D warnings` 无告警；模块边界清晰 | CI 命令 |
| 可用性 | 中文字体自动加载；窗口 1440×900 可完整显示；明暗两套主题 | 启动验证 |
| 安全 | 不写系统目录；只在项目目录写可选快照；不访问网络 | 代码审阅 |

```
Instrument  标的（代码 / 名称 / 市场 / 基准价 / 波动率）
Candle      ts, open, high, low, close, volume（价格均为 Price 整数）
Tick        ts, last, bid, ask, volume, prev_close
Order       id, symbol, side, kind, price, qty, filled_qty, status, owner, ts, reject_reason
Trade       id, taker/maker 单号, symbol, price, qty, taker_side, user_side, fee, ts
Position    qty, available, locked_today, cost_basis, realized_pnl, last_price
Account     cash, initial_cash, positions, realized_pnl, total_fees, day_index
```

## 6. 验收标准（DoD）

1. `cargo test --workspace` 全部通过，用例覆盖：价格时间优先、部分成交、撤单、T+1、涨跌停拒绝、资金不足拒绝、手续费、回测无未来函数、CSV 解析、UI 单帧渲染。
2. `cargo run -p tdesk-cli` 打印完整端到端流程且断言账户守恒。
3. `cargo run -p tdesk-app` 打开窗口，可完成「选标的 → 买入 → 查看持仓 → 撤单 → 推进一日 → 卖出 → 跑回测」全流程。
4. `cargo clippy --workspace --all-targets` 无错误。
5. `cargo build --release -p tdesk-app` 产出可独立运行的二进制。

## 7. 风险与假设

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 被误认为可实盘 | 资金损失 | README 与 UI 顶部固定「模拟盘 · 非实盘」标识；不实现任何券商适配器 |
| 浮点金额误差 | 对账不平 | 价格/金额全部整数化，仅展示时转 f64 |
| 回测未来函数 | 结果虚高 | 信号 T 日收盘、T+1 开盘成交；测试中构造反例验证 |
| 合成行情与真实分布差异 | 策略结论不可外推 | 文档明确标注；提供 `CsvSource` 接入真实历史数据 |
| egui 默认字体无中文字形 | 界面乱码 | 运行时加载 macOS `Arial Unicode.ttf`，缺失时降级并提示 |

## 8. 已知简化（首版）

1. 港股价位阶梯（不同价格区间最小价位不同）简化为统一 0.01；`MarketRules` 已预留扩展点。
2. 市价单按 IOC 处理（未成交部分自动撤销），未实现 FOK / 冰山单 / 止损单。
3. 未实现分红送转、融券卖空、盘前盘后、集合竞价与逐笔成交回放。
4. 合成行情使用几何布朗运动 + 日内扰动，不含跳空缺口与停牌逻辑。
